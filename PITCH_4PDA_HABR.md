# [Анонс] DeepNight SDK: Инструменты для Android TV, которые мы заслужили

Привет, 4PDA! Вы знаете меня как разработчика **DeepNight Launcher**. За время работы над лончером я написал много велосипедов: умную навигацию, чтобы фокус не прыгал, нативный аудио-движок на C++ для визуализации и VAD, и лингвистический модуль для поиска фильмов.

Сегодня я решил выпустить всё это в виде **DeepNight SDK**. Теперь любой разработчик ТВ-приложений или игр может использовать эти технологии.

### Что внутри?

1.  **TV Input Core**: Идеальный фокус для Compose. Больше никаких «потерь» фокуса при прокрутке. Плюс — поддержка Long Back для вызова системных меню.
2.  **DAP (DeepNight Audio Pipeline)**: Высокопроизводительный C++ движок. FFT-анализ и VAD (детектор голоса) прямо «на металле» с минимальными задержками.
3.  **Text Tools (Native Russian)**: Моя гордость. Нативный стеммер и фонетический поиск. Позволяет находить фильмы, даже если пользователь ошибся в названии.
4.  **Premium UI Kit**: Готовые «неоновые» компоненты в стиле Ultimate OS.

### Почему это круто?
*   **Производительность**: Всё тяжелое (звук, текст) вынесено в C++.
*   **Изоляция**: Модули независимы. Не нужно тащить весь лаунчер.
*   **Unity Ready**: Есть готовый Bridge для интеграции DAP в игры.

### Как попробовать?
Заходите на GitHub, качайте `sample-app`. Все модули доступны в виде `.aar` для легкого подключения.
